# [smsharma.io](https://smsharma.io)

Personal website. Plain static HTML/CSS — no build step, no dependencies.

- `index.html` — homepage; styles in `styles.css`
- `teaching/ds595-ai4science.html` — DS 595 course page (inline styles)
- Deploys via GitHub Pages from the `master` branch (custom domain in `CNAME`)

Preview locally with `python3 -m http.server` from the repo root.

The CV link points to [smsharma/CV](https://github.com/smsharma/CV) via jsDelivr, so it always serves the latest built PDF.
